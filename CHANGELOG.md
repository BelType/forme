# Changelog

## Unreleased

- **Transparent text is invisible text, and the display list is version 8** (2026-11-18, Egildo's ruling of that day; Caster's DESIGN.md S110). A list's `Fill` reads an optional `alpha`, from 0 up to but not including 1, absent where the paint is opaque, and the reader refuses a list of any version but 8. A run at alpha 0 is written in text render mode 3, `3 Tr` before its `Tf` and `0 Tr` after its last `TJ`, so its words keep their glyphs, ToUnicode, marked content and structure and stay searchable and claimed while nothing is painted; a run between 0 and 1 is set under the vector items' shared `/ExtGState` for that `/ca` (`GT<n>`, `Vectors::alpha_state`) and put back under the one for `/ca 1`, after its overprint state is set and before that is put back, so overprint and alpha are two states set in order, each with its own keys; a rectangle's alpha is set after its overprint state, inside the `q … Q` that puts it back. A declared ink keeps its colour and takes the alpha. The validator refuses an alpha outside that range in the oracle's sentence. A list with no alpha writes the file it wrote at version 7, byte for byte, on every committed list.

- **The archival claim** (2026-11-17, *the standard is a list* and *an archival claim is kept or refused* in `codeberg.org/BelType/decisions`; Caster's DESIGN.md S109). The list's `info` reads an optional `archival`, `pdfa4`, absent from every list that makes no such claim, so such a list writes the file it wrote. Under it the writer writes the PDF/A-4 identification in the XMP after any PDF/UA-2 block (`pdfaid:part` 4, `pdfaid:rev` 2020, no conformance level), no document information dictionary (its object number stays a free entry), `/Interpolate false` on every image and raster fallback, and a `GTS_PDFA1` output intent beside the `GTS_PDFX` one, both on the one profile object. The validator refuses, in Caster's sentences, an archival list with no colour story, one that places a facsimile, and one with CMYK colour (a declared ink, black text under `blackText: '100k'`, a CMYK paint or gradient, print marks, `DeviceCMYK` samples or a four-component JPEG) when the output profile is not CMYK. **Found on the way and fixed**: an RGB output profile, which Caster's TypeScript writer writes when no CMYK profile is given, was refused here as "not CMYK", and the profile stream was written with `/N 4` whatever its colour space; it is now written with `/N 3`, and a profile that is neither is refused in the oracle's sentence, "not CMYK or RGB". Measured 2026-11-17, veraPDF 1.30.4: the committed `roads`, `vector-roads` and `convert-text` lists with the claim (and the CMYK profile they carry), and `paper`, `vectors` and `canvas` with the claim and an sRGB colour story, pass both `-f 4` and `-f ua2`.

- **Every transparency group names the managed colour space** (2026-11-17, *an archival claim is kept or refused* in `codeberg.org/BelType/decisions`, one of its two corrections owed by every file). Under a colour story an opacity group and a soft mask's group now carry the document's sRGB profile as their `/CS`, `[/ICCBased n 0 R]`, as a group that held a blend already did; before they said `/DeviceRGB` under colour management too. With no colour story every group still says `/DeviceRGB`. A file with no transparency, or with no colour story, is byte for byte what it was.

- **The older tag names are written in the older namespace** (2026-11-17, *the older tag names are written in the older namespace* in `codeberg.org/BelType/decisions`). The list's structure element reads two optional members, `namespace` and `refs`, and an attribute object may carry `NoteType`. The tree writes a second `Namespace` object, `http://iso.org/pdf/ssn`, right after the 2.0 one and only in a file where an element names it, points each such element's `/NS` at it and lists it second in the root's `/Namespaces`, and writes `/Ref`, the elements' references in order, after `/A` and only on an element that has some. The validator refuses a namespace that is not the PDF 1.7 one, an empty `refs` and a `refs` index out of range, in Caster's sentences. A list that holds none of these writes the file it wrote.

- **A kept writer hashes a blob once** (2026-11-16, Egildo's ruling of that day, *we can flag an option to keep fonts*). The module's `Writer` gains `lacks(keys)`, `writeKept(listJson, keys)` and `forget(key)`, and the crate gains `write_trusting`, `write` with the blobs a caller vouches for left unhashed. A blob is hashed where `write` hashes it, on the first write that uses it after it arrived, and refused there with `write`'s sentence; a blob a write refused is not kept, and a blob handed again under its key is hashed again. `writeKept` writes with the blobs the list names and no others, so a kept writer's other blobs change nothing. `write`, and every write of a fresh `Writer`, is what it was. Measured 2026-11-16 in node, forty writes after five, load average about 4 (indicative): on the paper specimen, whose three font programs are 2.7 MB, the speed build's write is 22.0 ms with a fresh writer and 12.7 ms kept; on a bill of 61 rows 15.5 and 13.1 ms; the files are the same bytes. The module grew from 1 519 698 to 1 547 817 bytes and its glue from 11 355 to 14 976, 1 562 793 together, within the 1 600 000 of the budget. Tested natively by `a_trusting_write_hashes_only_the_blobs_it_is_not_told_were_hashed_and_writes_the_same_bytes`, and in the module by Caster's `test/forme.test.ts`.

- **The module is built for speed** (2026-11-16, Egildo's ruling of that day). The `wasm` profile's `opt-level` is `3`, no longer `"z"`, and Caster's `scripts/bundle-forme.js` runs `wasm-opt -O3` in place of `-Oz`: the module is loaded once and kept warm by a server, so the write is paid on every print and the size once. Measured 2026-11-16 in node, the vendored glue on the calling thread, forty writes after five, load average about 4 (indicative, a busy machine): the paper specimen's write fell from 28.3 to 22.0 ms (22 %) and a bill of 61 rows from 20.7 to 15.5 ms (25 %); the survey of that day measured 19 % and 25 %. Every file is byte for byte the size build's: the nineteen lists of Caster's `fixtures/lists/` through `npm run identity -- replay --writer forme`, and the paper's and the bill's dumped lists. The module grew from 940 796 to 1 519 698 bytes, and the budget, glue included, from 1 061 704 to 1 600 000.
